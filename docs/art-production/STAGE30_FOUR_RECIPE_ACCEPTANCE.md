The adapter validates reviewed receipt/request/spec/output digests, source
family, nine-category coverage and existing compatibility rules. It does not
decode artwork, authenticate a human owner or assert reconstruction from a
metadata receipt. Actual decoding/reconstruction is independently performed
by the existing bounded renderer. Local hash-pinned review JSON is trusted
operator evidence, not a public upload or authorization service.
