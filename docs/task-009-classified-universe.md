# LAMMB Labs — classified universe

The public Universe is an original fictional dark-comedy archive. This is entertainment, independent of the collection engine and live launch state. No fictional seal status or specimen number is an onchain event, mint signal, rarity claim or token assignment.

## Canon

The secret laboratory engineered a species incapable of irrational financial decisions. Success lasted approximately eleven seconds. Four early subjects traded food for a monkey picture, paid a 400% markup, started a motivational podcast and convinced scientists to provide exit liquidity. Eventually 5280 unqualified specimens were sealed. Mutations, skeletal anomalies and selective pixel corruption developed. The fictional facility connected to Robinhood Chain; seals are beginning to fail. None of this asserts actual scientific research, financial products or blockchain events.

The four records form one narrative: Initiative → Subjects → Corruption → Lockdown. Eight original incident reports and four annexes are supplementary evidence, never gates to essential lore. No unrevealed specimen design is used. No television franchise elements, crowns, signage or rarity probabilities are added.

## Routes and progressive enhancement

`/universe` is the directory. `/universe/security`, `/universe/archive`, `/universe/surveillance` and `/universe/experimental` are ordinary destinations. `/universe/archive/000` through `/003` are statically generated deep links. Invalid file IDs return the existing 404.

All destinations, canonical narratives and evidence render on the server. Native links preserve refresh and browser history; native details expose optional incidents. Mobile has a compact directory and a two-column destination list on interior pages. No spatial control is required to navigate.

Two small client components enhance the fiction: a local diagnostic cycles through original jokes with a polite status announcement; an annex uses the existing native dialog helper with Escape, contained focus, inert background, scroll locking and focus restoration. With JavaScript disabled the diagnostic control is hidden and annexes become native disclosures. No simulated login, clearance challenge, user identity or network request exists.

## Episode catalog

`@lammb/schema/labs` defines a strict discriminated editorial schema. IN_DEVELOPMENT requires null media and release date. PUBLISHED requires a local video file, WebP poster, at least one language-labeled VTT caption file, transcript and valid date. IDs must be unique. Episode 001 — Exit Liquidity has no video, poster pretending to be footage, release date or player.

Future publication requires externally produced files, rights review, verified media integrity, caption/transcript review and accessible playback acceptance before changing editorial status. The schema is a foundation, not a video production pipeline or a guarantee that files exist.

A baseline checkout of authorized main in the disposable runner provides same-run laboratory comparison; measurements are unthrottled localhost data, not field Core Web Vitals. No physical iPhone or screen reader claim is made.
